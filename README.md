# Awesome List Contributor Badge Generator

Show off your community size! This tool fetches the contributor count for any GitHub repository and generates a custom SVG badge, perfect for your README.

## Features

-   **SVG Generation**: Creates a high-quality SVG badge locally.
-   **Customizable**: Supports custom labels and colors.
-   **GitHub Integration**: Fetches real-time contributor counts (requires API access).

## Installation

```bash
npm install -g awesome-contributor-badge
```

## Usage

Generate a badge for a repository:

```bash
awesome-contributor-badge owner/repo
```

This will create `badge.svg` in the current directory.

## Options

-   `-o, --output <file>`: Output filename (default: `badge.svg`).
-   `--label <text>`: Badge label (default: `Contributors`).
-   `--color <color>`: Badge color (default: `blue`).
